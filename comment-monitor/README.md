# Comment intake 1.1.0

Read-only collection of public YouTube and TikTok comments and replies to private local storage. TikTok uses the official Social MCP service with user.info.basic, video.list and comment.list permissions. It does not read Facebook, choose topics, generate videos, publish, or read hidden comments. Provider errors fail closed; complete scans reconcile removed comments. No raw comments or credentials belong in this repository.
